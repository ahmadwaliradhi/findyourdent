# GCP cost research: hackathon window (seen 2026-10-16)

All prices are USD list prices, read from primary pages on 2026-10-16. Nothing was signed into or submitted.
Name changes as of today: "Vertex AI" is now **Gemini Enterprise Agent Platform**, and "Vertex AI Search" is now **Agent Search**.

## 1. Places API (New)
Source: https://developers.google.com/maps/billing-and-pricing/pricing (seen 2026-10-16). Prices are for the first tier, 0 to 100k calls per month.

| SKU | $/1,000 | Free calls/month |
|---|---|---|
| Text Search Essentials (IDs Only) | free | unlimited |
| Text Search Pro | 32.00 | 5,000 |
| Text Search Enterprise | 35.00 | 1,000 |
| Text Search Enterprise + Atmosphere | 40.00 | 1,000 |
| Nearby Search Pro / Enterprise / Ent + Atmosphere | 32.00 / 35.00 / 40.00 | 5,000 / 1,000 / 1,000 |
| Place Details Essentials (IDs Only) | free | unlimited |
| Place Details Essentials | 5.00 | 10,000 |
| Place Details Pro | 17.00 | 5,000 |
| Place Details Enterprise | 20.00 | 1,000 |
| Place Details Enterprise + Atmosphere | 25.00 | 1,000 |
| Place Details Photos | 7.00 | 1,000 |

Field to SKU mapping, from https://developers.google.com/maps/documentation/places/web-service/data-fields (seen 2026-10-16). One request is billed at the highest SKU of any field in its field mask.
- `id`: Essentials IDs Only, for both Text Search and Place Details.
- `displayName`: Pro.
- `formattedAddress`, `location`: Essentials in Place Details, Pro in Text Search.
- `photos` (references only): IDs Only in Place Details, Pro in Text Search. Fetching the image itself is billed as Place Details Photos.
- `rating`, `userRatingCount`, `regularOpeningHours`, `currentOpeningHours`, `nationalPhoneNumber`, `internationalPhoneNumber`, `websiteUri`: **Enterprise**.
- `reviews`: **Enterprise + Atmosphere**.

## 2. Gemini on Agent Platform (formerly Vertex AI)

Prices are per 1M tokens for prompts of 200k tokens or less. Text, image, video and audio input are all billed at the same input rate.

- Output prices include reasoning ("thinking") tokens. Cached input costs about 10% of the normal input price.
- The "intro" and "promo" prices are applied as 50% credits back on net spend.
- **No current GA Flash or Pro model lists asia-southeast2 (Jakarta).** Of the GA Flash models, only Gemini 3.5 Flash runs in asia-southeast1 (Singapore). Use the `global` endpoint for 3.8 Flash.
- Image tokens: the pricing page lists 1,120 tokens per input image for 3.1 Flash Image and 258 tokens per image for Live API. I did not find a figure for 3.8 Flash; the estimate below assumes up to 1,120 tokens per image.
- Grounding with Google Search or Maps: 5,000 queries per month free, then $14 per 1,000. Grounding with your own data: $2.50 per 1,000 prompts.

## 3. Agent Search (formerly Vertex AI Search)
Source: https://cloud.google.com/generative-ai-app-builder/pricing (seen 2026-10-16). These are pay-as-you-go prices.
- **Free trial: 10,000 queries per account per month.** This does not cover Advanced Generative Answers.
- Search Standard Edition: **$1.50 per 1,000 queries**.
- Search Enterprise Edition, which includes Core Generative Answers (AI Mode): **$4.00 per 1,000 queries**.
- Advanced Generative Answers add-on: +$4.00 per 1,000 queries.
- Index storage: $0.006849315 per GiB-hour (about $5 per GiB-month). **10 GiB per month is free.**

## 4. Cloud Run
Source: https://cloud.google.com/run/pricing (seen 2026-10-16). asia-southeast1 and asia-southeast2 are both **Tier 2** regions. The free tier is applied as a spending-based discount at Tier 1 (us-central1) rates, totalled per billing account per month.

| Billing mode | Free tier per month | Tier 2 CPU per vCPU-second | Tier 2 memory per GiB-second | Requests |
|---|---|---|---|---|
| Request-based | 180k vCPU-s, 360k GiB-s, 2M requests | active 0.0000336, idle min instance 0.0000035 | active 0.0000035, idle 0.0000035 | $0.40 per 1M |
| Instance-based | 240k vCPU-s, 450k GiB-s | 0.0000216 | 0.0000024 | none |

Cost of one min instance (1 vCPU, 512 MiB) left idle in asia-southeast2, before the free tier:
- Request-based, 30 days (2,592,000 s): 9.07 (CPU) + 4.54 (memory) = **$13.61 per month**. That is $10.43 for 23 days.
- Instance-based, 30 days: 55.99 + 3.11 = $59.10 per month.

## 5. Free tiers
- **Firestore** (default database only; named databases get no free quota): 1 GiB stored, 50k reads/day, 20k writes/day, 20k deletes/day, 10 GiB egress/month. Sources: https://cloud.google.com/firestore/pricing and https://firebase.google.com/pricing (seen 2026-10-16).
- **Cloud Storage**, Always Free: 5 GB-months Standard storage, 5k Class A operations, 50k Class B operations. **This applies only in us-west1, us-central1 and us-east1.** Source: https://cloud.google.com/storage/pricing (seen 2026-10-16).
- **Firebase Hosting** (Spark plan): 10 GB storage, 360 MB/day transfer. Source: https://firebase.google.com/pricing (seen 2026-10-16).
- **Firebase Auth / Identity Platform**: 50k MAU free, which covers Google sign-in. SAML/OIDC: 50 MAU. Source: same page.
- **Artifact Registry**: 0.5 GB storage per month free per billing account. Source: https://cloud.google.com/artifact-registry/pricing (seen 2026-10-16).
- **Cloud Build**: 2,500 build-minutes per month on e2-standard-2 in the default pool. Sources: https://cloud.google.com/build/pricing and the free-tier docs. Note that https://cloud.google.com/free still says "120 build-minutes per day".
- **Secret Manager**: 6 active secret versions, 10k access operations and 3 rotation notifications per month. Source: https://cloud.google.com/secret-manager/pricing (seen 2026-10-16).

## 6. Credits
- **Google Cloud Free Trial: $300 credit to spend over 90 days.** It is only for accounts that have never paid for Google Cloud, Maps Platform or Firebase. It cannot be used for Gemini API in AI Studio or for partner generative-AI models. The docs do not say whether it covers Maps. Sources: https://cloud.google.com/free and https://docs.cloud.google.com/free/docs/free-cloud-features (seen 2026-10-16).
- **Maps Platform: the $200 monthly credit ended on 2025-03-01.** It was replaced by free usage caps per SKU: 10k Essentials, 5k Pro and 1k Enterprise calls per month. Source: https://developers.google.com/maps/billing-and-pricing/faq (seen 2026-10-16).

## 7. Estimate for the 23-day window (2026-10-14 to 2026-11-06)
The window spans two calendar months. The evaluation days split 13 in October and 6 in November (about 68% / 32%), and each month gets its own free caps.

Assumptions:
- Gemini 3.8 Flash on the global endpoint at the intro price.
- Each agent call is 3k input and 800 output tokens.
- Each moderation call is about 3.2k input (1k text plus 2 images at 1,120 tokens) and 300 output tokens.
- Each price-list extraction is 10k input and 2k output tokens.
- The agent service runs in asia-southeast2 with request-based billing and about 30 s of active time per session.

| Line item | Low | Expected | High | Notes |
|---|---|---|---|---|
| Gemini, agent (8,000 calls: 24M in, 6.4M out) | 31.20 | 42.00 | 72.60 | Low: 2k of the input tokens cached. High: output doubled by thinking tokens, non-global price |
| Gemini, moderation (300) + extraction (20) | 1.40 | 1.40 | 2.50 | |
| Agent Search (4,000 queries) | 0 | 0 | 16.00 | Covered by the 10k free trial queries each month. High: Enterprise edition with no free trial |
| Search index storage | 0 | 0 | 0 | Under 10 GiB |
| Text Search (2,000) | 0 | 12.88 | 40.00 | Low: Pro field mask. Expected: Enterprise, because the cards show `rating` (368 calls billable). High: Ent + Atmosphere, all in one month |
| Place Details with rating and reviews (6,000) | 26.00 | 100.00 | 125.00 | Ent + Atmosphere $25 per 1,000. Expected: 4,000 billable after both months' caps. Low: dedupe halves the calls. High: one month's cap only |
| Place Photos | 0 | 0 | 35.00 | High: 1 photo per Details view |
| Cloud Run agent (1 min instance) | 3.00 | 12.24 | 45.30 | Low: free tier applied. Expected: list price ($10.43 idle + $1.81 active). High: instance-based billing |
| Cloud Run web (scale to zero) | 0 | 0 | 2.00 | Within the free tier |
| Firestore, GCS, Hosting, Auth, Artifact Registry, Build, Secrets, egress | 0 | 1.00 | 5.00 | GCS outside US regions and Artifact Registry over 0.5 GB cost a few cents |
| **Total (USD)** | **~62** | **~170** | **~343** | |

Notes:
- The two biggest items are Place Details with reviews (about 59% of the expected total) and Gemini (about 25%). Leaving `reviews` out of the field mask moves Details down to Enterprise ($20 per 1,000). Caching `place_id` lookups and loading reviews only on demand cuts this line the most.
- The $300 trial credit would cover the expected total if the account is new. It is not confirmed that the credit applies to Maps SKUs.
- Gemini 4 Argon's promo price ends on 2026-11-30, and Gemini 3.8 Flash's intro price ends on 2026-12-31. Both are inside or past this window, so the window is billed at the lower prices.
