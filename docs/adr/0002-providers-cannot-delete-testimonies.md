# Providers can reply to and report Testimonies but never delete them

Testimonies are the A1 trust signal, so a Provider deleting unfavourable ones would make them worthless. Instead a Provider can reply publicly or report a Testimony; Gemini screens every Testimony before publication (personal data, defamatory accusations, medical claims) and reported Testimonies go to manual review by the FindYourDent team, which is the takedown path Permenkominfo 5/2020 requires. Removal is a platform moderation decision, never a Provider action.

The author, by contrast, can always edit (re-moderated) or delete their own Testimony, which is also their right to erasure under UU 27/2022.
