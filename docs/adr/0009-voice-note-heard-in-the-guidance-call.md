# A voice note is heard in the Guidance call, so its checks run on the transcript

Spec 01 wants the deterministic Emergency Escalation rule to run before any model call, and Agent Search to ground every Guidance. A voice note has no text until Gemini hears it. We considered a separate speech-to-text call first and rejected it: it would be a third Gemini call per session (the spec allows two) and add latency for the Patients who most need speed. Instead the voice note goes to Gemini as native audio in the one Guidance call, which returns a transcript with its answer. The deterministic rule and the injection check then run on the transcript and can still escalate or redirect, and Gemini's own red flags escalate even when it could make out no words. A voice turn is grounded on the curated knowledge files only, since there is no text to search with before the call. The transcript fills the complaint box; a corrected transcript, or the answer to the follow-up question, is sent as text and goes through the typed path, Agent Search included. If Gemini is unavailable for a voice note, the Patient gets the retry state with no escalation, so the record button sits beside the complaint box, not in place of it.
