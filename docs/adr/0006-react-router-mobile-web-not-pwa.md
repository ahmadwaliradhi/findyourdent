# Web app: React Router v7, mobile-first responsive, not a PWA

The specs first named a Next.js progressive web app. We chose React Router v7 in framework mode (TypeScript, server rendering, loaders and actions, resource routes for the web API) instead: it keeps server-rendered, indexable Listed Provider and feed pages and the web API in one Cloud Run service, with the React ecosystem agents know best, without adopting Next.js. We dropped PWA features (install prompt, service worker, offline) because Patients mostly use phones but visit rarely, around a toothache, so installation adds work without return; every screen is instead designed mobile-first and tested at small phone widths. Lighthouse is run for performance, accessibility, best practices and SEO, not the PWA category.
