Card groups one thing a Patient reads as a unit: a Guidance section, a price estimate, a Provider. It is a `section` with a heading; pass `labelledBy` with the id of that heading.

The consumer provides the heading (`fyd-card__title`), optional description, and the content; the card supplies 20px padding and 16px gaps. Use the default for most content, `flat` inside another card or on a list, and `emergency` only for the IGD instruction: it adds `role="alert"`, a danger-soft ground and a 2px danger border, and the title turns danger-colored at 24px. Don't nest more than one level of cards and don't put the emergency variant next to promotional content.
