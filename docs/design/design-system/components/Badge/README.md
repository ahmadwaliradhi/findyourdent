Badge labels the state or kind of something small: a Provider type, a verified visit, a low-confidence price. The status variants (`success`, `warning`, `danger`, `info`) include an icon automatically so the meaning never relies on color alone.

The consumer provides short text (one to three words, sentence case). Use `neutral` or `outline` for kinds, `brand` for a program such as BPJS, and a status variant only for a real state. Don't use a badge as a button, don't wrap it onto two lines, and don't put more than three on one card.
